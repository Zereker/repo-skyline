# Repo Skyline 60 秒 Demo

## 0-5s — 城市出现

镜头默认斜俯视。

旁白：

> “Every repository has a skyline.”

展示当前 Repository 的完整城市。

---

## 5-12s — 回到第一 Commit

拖动 Timeline 到最左。

点击 Play。

第一个文件从地面长出来。

旁白：

> “Every commit builds the city.”

---

## 12-25s — 城市成长

保持 2x / 5x 播放。

连续展示：

- Added → 建筑生长
- Modified → 黄色脉冲
- Renamed → 紫色高亮
- Deleted → 红色拆除

不要停留在普通 Commit。

---

## 25-35s — Release

点击 Timeline 上的 Release marker。

画面显示：

> Release vX.Y.Z

然后继续播放。

旁白：

> “Releases become milestones in the city's history.”

---

## 35-47s — Story Mode

点击 Play story。

依次展示：

1. First commit
2. Major builder
3. Biggest construction wave
4. Urban renewal
5. Release

相机自动推进到对应建筑区域。

---

## 47-55s — Contributor Territory

切换：

District → Contributor Territory

城市建筑切换为 Contributor 颜色。

旁白：

> “The skyline also reveals who built which part of the city.”

---

## 55-60s — 收尾

回到当前 Commit。

展示：

- 当前 commit message
- file changes
- release badge
- 当前城市

最后一句：

> “Repo Skyline turns Git history into a living city.”

## Demo 规则

- 优先使用有明显 release history 的真实开源仓库。
- 建筑数量建议控制在 1,000–2,500。
- 选择有明显 rename / delete / large-change 的仓库。
- Story Mode 不需要完整展示所有 Commit，只展示自动识别的关键事件。
- 60 秒内不要解释技术实现，先让视觉效果成立。
